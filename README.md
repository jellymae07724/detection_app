# Detection_App

Live Object Detection, Counting & Alerts using Streaalit and YOLOv8

This project is a real-time object detection systes built using Streamlit, YOLOv8, and WebRTC. It detects objects from a live webcam feed, counts selected objects, and displays alerts when the number of detected objects exceeds a chosen threshold. 

📌Features

Real-time webcam object detection
Detects multiple objects using YOLOv8
Object counting feature
Custom object selection
Alert system when object count exceeds limit
Live annotated video display

Technologies Used

Python
Streamlit - for the web interface
streamlit-webrtc for webcam streaming
YOLOv8 (Ultralytics) - for object detection
OpenCV - for image processing
AV - for video frame handling
